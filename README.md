# Nova Market — Full-Stack Deployment & Project Architecture

A responsive product catalog capstone demo with a modular HTML/CSS/JavaScript structure.

## Features
- Responsive desktop and mobile layout
- Product catalog with search and category filtering
- Sort products by price ascending or descending
- Interactive shopping cart with quantity controls and subtotal
- Cart state retained for the browser session
- Accessible form labels, dialog controls, and live status messages
- Demo checkout notice; no real payments are taken

## Run locally
Open `index.html` in a modern browser. No build step or API key is required.

## Deploy
Upload `index.html`, `styles.css`, and `app.js` to the root of a static hosting repository, or deploy this folder to GitHub Pages, Netlify, or Vercel.

## Project structure
- `index.html` — page structure and cart dialog
- `styles.css` — responsive styling and product illustrations
- `app.js` — product data, filtering, sorting, cart state, and event handlers

## Scope
This is a front-end capstone storefront demo. It does not include a backend, user accounts, inventory synchronization, or payment processing.
