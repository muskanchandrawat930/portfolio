# Real-Time Weather Dashboard

Complete task implementation for **Asynchronous JavaScript & RESTful APIs**.

### Requirements covered
- Fetch API with async/await
- Public REST API integration
- Error handling for network/HTTP failures
- Nested JSON parsing and dynamic rendering
- City search functionality
- Temperature, humidity, wind speed and condition
- 7-day forecast
- Responsive UI

### API
Open-Meteo Geocoding API + Forecast API. No API key required.

### Run
Extract the ZIP and open `index.html` in a modern browser with internet access.
